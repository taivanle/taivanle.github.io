02 / THE PROBLEM

Evaluation should be as useful as the model.

Evaluating model-generated artefacts needs more than a plausible-sounding answer. The grader has to assess correctness against expected outputs and explicit criteria, while keeping repeated benchmarking affordable and reproducible.

01Cost per run
02Consistency across models
03Rubric-level explainability

The problem that shaped the engineering decisions.

03 / THE ARCHITECTURE

Follow the system, stage by stage.

Select a stage to explore the design.

STAGE 01

Model artefact

Start with model-generated artefacts, expected outputs, and the criteria in a structured rubric. The test conditions make the score meaningful.

STAGE 02

Deterministic checks

Use deterministic validation for machine-checkable properties. These checks create a repeatable foundation for the rest of the assessment.

STAGE 03

Rubric & model grading

Assess the remaining criteria with rubric-guided model judgement in a controlled evaluation environment.

STAGE 04

Benchmark report

Bring the results into a repeatable benchmark report and compare quality, evaluation time, and cost across the tested workflows.

KEY DESIGN DECISION

Different criteria need different graders. Combining deterministic checks with rubric-guided model assessment creates a clearer boundary between what can be verified directly and what requires judgement.

Conceptual flow · simplified to explain the engineering approach.

04 / THE BUILD

What I designed and implemented.

01

Hybrid grading

Designed and implemented Themis as a hybrid grading pipeline: deterministic validation for machine-checkable properties, rubric-based assessment, and LLM judgement for the remaining criteria.

02

Execution environments

Built custom evaluation environments that execute grading workflows end to end and compare model outputs with golden datasets and structured rubrics.

03

Repeatable benchmarking

Automated repeatable benchmarking across multiple models and compared the approach with Gandalf the Grader and LLM-as-a-Judge methods.
